# Portfolio demo samples

These small, fictional files are the sources used in the Rocky 0.14.1 portfolio
screenshots and walkthrough, captured on 11 November 2026.

- Open `sample-project-brief.txt` on the **Documents** page, wait for **Ready**,
  and ask: “What is the project deadline and budget? Give the source references.”
  The source states **20 November 2026** and **500 dollars**.
- Select the `task-tracker` folder on the **Code** page and ask:
  “Explain how TaskTracker stores tasks and returns pending tasks. Keep it
  concise and cite the code.” The example stores tasks in a list and filters
  incomplete tasks with a list comprehension.

The video uses a separate demo database with fictional reminders. It uses local
Ollama models and text input. No microphone or desktop audio is included, and
processing waits are shortened. Model wording and response times can vary.

The public assets are in [`../media`](../media/). Raw footage, the demo database
and capture scratch files stay under the ignored `build/` directory.
